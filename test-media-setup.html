🎪 Test Media Setup

Quick Start

This page helps you generate test media files for the Flea Circus show control system.

The system is designed to work with your own media files, but these tests help verify everything is working.

Using Your Own Media

Recommended approach: Use your own video and audio files.

Simply copy files to these folders:

  • media/video/ - Add your .mp4 files
  • media/audio/ - Add your .mp3 files
  • media/images/ - Add your .png or .jpg files
Step 1: Copy Your Media Files
Place video files, audio files, and images into the appropriate folders.
Step 2: Refresh the Operator Console
The media library will automatically load your files. Just refresh the browser.
Step 3: Click and Play
In the operator console, click any media item in the library to play it.
💡 Pro Tip: Media files are loaded automatically. No code changes needed. Just copy, refresh, and go!

Supported Formats

Video:
.mp4 (Recommended) • .webm • .ogv
Works best with H.264 codec (most common)
Audio:
.mp3 (Recommended) • .wav • .ogg • .m4a
Images:
.png • .jpg • .gif • .svg

Tips for Best Results

  • ✅ Use MP4 format for videos (best browser compatibility)
  • ✅ Use MP3 format for audio (widest support)
  • ✅ Keep files reasonably sized (under 50MB is ideal)
  • ✅ Use descriptive filenames: interview_guest_name.mp4
  • ✅ Test on your actual display device (projector/TV)
  • ✅ Have audio files ready for transitions
  • ✅ Create title/credit graphics as images or videos
